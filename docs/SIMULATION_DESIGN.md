# V37 시스템 스케치

## 1. 한 사례를 게임에서 체험하는 실제 과정

**1847년 겨울, 빵집과 빈민의 세계:** 밀가루 가격이 오름(시장 공급 사건) → 제빵사가 출근해 실제 밀가루 재고가 부족함을 발견 → 가격표를 바꾸거나 크기를 줄이는 직업 행동 수행 → 가난한 안나는 아침 식비가 부족해 고민 → 근처 신문 구독자들은 물가에 관한 짧은 논평을 나눔 → 사용자는 (a) 관찰하고 기사/소문 확인 (b) 제빵사에게 품삯과 가격 협상 (c) 안나에게 빙의해 일자리·외상·교구 구제 중 택일 (d) 제빵사에게 빙의해 빵값·원료 주문을 결정. 어떤 선택에도 주민의 돈·빵 재고·건강·가게 평판이 지속적으로 변함. 가짜 신문 기사는 명확히 극중 재구성으로 표기. 물가 기록 수치는 현재 초안으로 임의 입력 금지.

## 2. 인물 행동 의사결정 예시

`needs = hunger .9 + rentArrears .7 + workObligation .8 + socialTie .5 + risk .2` 같은 기초 상태가 있을 때, actor 후보 행동을 만들고 능력/근무시간/돈/법/거리/도구/사건 우선도를 평가. 최고 유효한 `goal`의 행동 순서를 선택하고 walk graph의 도로를 따라 걸음. 실패하면 갈 수 있는 대체 행동을 찾고 기록. API 호출 없이 deterministic seed로 반복 가능.

## 3. 정보가 실제로 퍼지는 과정

실제 사건을 **직접 본 사람**은 직접 경험(source witness)으로 기억. 뒤늦게 주변에서 듣는 사람은 source speaker/시간/confidence를 지닌 **소문**으로 기억한다. 상급 관청이 자료를 공식 접수하지 않으면 플레이어의 개인 메모를 모른다. AI에게는 해당 NPC의 실제 knowledge graph만 제공. 누군가의 이념도 소문을 받아들이는 방식에 영향을 주지만 사실 자체를 변조하지 않음.

## 4. 사망·폭력·범죄의 역사적 정합성

가상 인물은 배고픔/질병/사고로 사망할 수 있고 유효하게 문턱을 넘은 폭력 선택은 피해·목격·수사·법적 처분으로 이어진다. 사건 진행을 동작 방법 안내로 만들어선 안 되며 폭력 표현은 비선정적. 니콜라이 1세 등 역사 실존 인물의 필연적 역사 결과는 바꾸지 않는다. 반사실 문학 인스턴스에서만 대체결말 제공, 정식 역사 기록으로 보도 금지.

## 5. 구현 우선순위

S1: 1지구/6명/식당-노동-방세-우편-출판 5개 원인 연동 사건의 실제 플레이. S2: 3지구/18명/20사건 + 가구와 주거. S3: 6지구/36명/45사건 + 신문·소문. S4: 18세기/19세기 후반 문학 인스턴스와 5엔딩 확장. 각 단계는 전 단계 시뮬레이션/브라우저 PASS 후 진행. 자료 접근 불가로 역사 verification BLOCKED 상태면 허구 생활 사건으로 역사 자료 PASS를 대신하지 않음.
