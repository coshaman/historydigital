# 1840년대 상트페테르부르크 도트 RPG — 비주얼 시안/제작 명세

## 화면 방향
- Top-down 3/4 pixel view, 기본 타일 32×32 혹은 48×48, 고정 픽셀 스케일과 캐릭터 격자 크기 유지. 1840년대 러시아 수도의 석조 건물, 강·운하, 마차, 관청, 빈민 공동주택, 상점, 시장으로 인식 가능해야 함.
- 무조건 중세판타지 RPG Maker 기본 타일셋/임의 서유럽 고성으로 때우지 말 것. 건축 디테일(층수·창문 비례·돌 포장·지붕 재질), 신분별 옷과 장비는 실제 19세기 출처 대조 전 연구 레퍼런스로 명시.
- UI는 '누가 되어 있는가 / 현재 집 / 배고픔과 돈 / 일이 언제 시작되는가 / 큰 신문과 편지 / 목격한 사건 / 선택' 중심. 장시간 읽기에는 별도 대형 parchment reader 사용.

## 에셋 생산 순서
1) 각 지구 tileset/충돌 맵/지붕·실내 transition → 2) 직업별 작업 도구(최소 15종) → 3) 36인 도트 옷/모자/체형/행동 애니메이션 → 4) 서적·문서·신문의 실제 그래픽/자료 확대 → 5) 날씨·낮밤·배경 이벤트(종소리/발자국/연기). 각 이미지의 출처/실 제작자/라이선스 기록; 실제 구입 에셋이면 재배포 권리 확인.
