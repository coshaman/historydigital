All records include the machine-readable fields `sourceId`, `date`, `edition`, `locator`, `originalRussian`, `koreanTranslation`, `classification`, `availableDate`, `url`, and `contextRangeId`. Each context range is marked `CONTIGUOUS_WITNESS_RANGE` and has separate RU/KO references. The UI keeps historical-source material separate from `LITERARY_BORROWING`; V42 uses no literary borrowing records.
