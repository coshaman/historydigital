# V42 false-equivalence warnings

These are authoring constraints, not player-facing ideology scores. The audit fails if a route collapses the historical distinctions below.

| forbidden shortcut | required correction |
|---|---|
| Official Nationality = Slavophilism | Separate a state education formula from government-outside intellectual movements. |
| Westernizer copies all Europe | Present the dispute over law, education, social reform and Russia's historical path. |
| Slavophile = ethnic nationalism | Distinguish communal life, Orthodox tradition and autonomous development from blood-line nationalism. |
| Gogol = government propaganda | Read the satirical work together with the 1847 duty, moral and Orthodox-hierarchical argument. |
| Belinsky = already a revolutionary socialist | Keep literary responsibility, institutional criticism and serfdom criticism in their 1847 setting. |
| Petrashevsky circle = one unified revolutionary party | Distinguish reading, discussion, Fourierist interest, participants and actual risk. |
| Table of Ranks = an ideology | Treat it as an administrative hierarchy governing status, promotion and incentives. |

The game exposes these distinctions through dated source context, not modern labels. The registry is in `falseEquivalenceWarnings` in the narrative JSON and is checked by `v42-ideological-history-audit`.
