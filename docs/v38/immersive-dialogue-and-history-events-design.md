# 대화·현장·역사 사건 설계

## 의도

러시아의 구체적인 생활·문화·역사 장면 안에서 인물이 플레이어의 말에 직접 반응하고, 플레이어가 주변 사람과 물건을 즉시 알아보며, 실제 역사 사건을 자료와 함께 체험하게 한다.

## 범위

1. AI 대화: 캐릭터 카드, 말투 예문, 현재 장면, 대화 기록을 분리해 전송한다. 답은 플레이어의 마지막 발화에 먼저 응답하고, 장면에 없는 추상적 토론·혼합 문장·인물 설정 밖의 사실을 거부 또는 한 번 교정한다.
2. 상호작용 표시: 현재 인물·장소·자료·퀘스트 조건에서 실제로 실행 가능한 상호작용 물체만 지도에 강조한다.
3. 생동감: 비조종 주민의 짧은 장면 대화, 사건별 표정·동작·군중 반응을 결정론적 상태와 낮은 빈도의 장식 대사로 표시한다. 장식 대사는 AI 호출이나 게임 상태 변경을 만들지 않는다.
4. 새 역사 현장 3개: 1825년 12월 14일 상원 광장 봉기, 1836년 고골 《감찰관》의 페테르부르크 공연, 1861년 농노해방 선언 공표. 기존 1848년 선언문·1849년 체포/총살 및 이미 구현된 독서 사건은 재사용하지 않는다.

## 현장 설계

- 각 장면은 자기 지도·출처·현장 인물·완료 조건을 가진다. 도입은 현장에서 바로 벌어지는 행동으로 시작한다.
- 각 장면에 4명 이상 참여 인물을 둔다. 한 인물과 이야기하는 사이 다른 주민이 정해진 이동 목표로 접근해 대화 참여자로 합류한다. 실제 역사 인물은 서버 허용 목록에서 빙의 불가다.
- 상호작용과 군중 반응은 기록되며, 정해진 역사적 결과는 플레이어 선택으로 바뀌지 않는다. 끝에서 선택의 범위와 실제 결과를 출처에 연결해 제시한다.
- 출처가 뒷받침하지 않는 군중 대사·장면 세부는 창작 인물의 허구 대사로 한정한다. 실제 인물의 발언처럼 제시하지 않는다.

세 장면은 1847년 캠페인 지도에 억지로 겹치지 않고 `역사 현장 3`에서 독립적으로 시작한다. 현재 구현은 화면형 그룹 장면이다. 플레이어는 첫 세 사람의 대화를 듣고 실무 방향을 고른다. 장면별 네 번째 사람이 다가와 합류한 뒤 후속 대화와 선택이 이어진다. 인물 이동 애니메이션과 자유 입력형 AI 그룹 채팅은 이번 패치에 포함하지 않았다.

## 프롬프트 연구에서 채택한 점

- SillyTavern 공식 문서의 역할 분리: 시스템 규칙, 인물 성격/예문, 상황, 플레이어 페르소나, 관련 지식, 대화 기록을 따로 배열한다.
- Reddit 캐릭터 대화 사례의 장면 규칙: 말은 현재 행동과 물리 장면에 붙이고, 사용자의 행동·대사를 대신 쓰지 않으며, 각 메시지에서 한 화자에 집중한다.
- 예시 문장을 장문으로 복제하지 않고, 짧은 인물별 음성 예문을 소수만 사용한다. 최근 입력과 관련 없는 사건 설명은 답변에서 제외한다.
- 유니챗 가이드의 캐릭터 구성과 다중 인물 요령: 정체성·성격·말투·관계·첫 장면을 분리하고, 여러 인물일 때는 인물 목록·관계·등장 조건을 명시해 한 인물이 대화를 독점하지 않게 한다.
- 디시인사이드 AI 채팅 갤러리 게시물의 프롬프트 작성 팁: 큰 지침부터 구체적 말씨·출력 규칙 순으로 구조화하고, 키워드만 압축하지 말고 완전한 문장으로 행동을 지시한다. 사건 흐름은 장면별로 끊어 인과를 분명히 한다. 성격 요소는 한꺼번에 과장하지 않고 현재 상황에 맞는 요소만 꺼내 쓴다.
- 아카라이브 링크는 제공받았으나 현재 브라우저 안전 정책이 열람을 차단했다. 내용을 확인하지 못했으므로 프롬프트 설계 근거로 사용하지 않는다.

## 구현 기록

- API 대화 규칙을 장면 지시와 별도로 보강했다. 마지막 발화의 말행위를 먼저 파악하고 첫 문장에서 직접 답하며, 장면 안의 물건·일을 짚는 짧은 확인 질문으로 이어가도록 했다. 실패 때 정적 대사를 답처럼 보여주지 않는 기존 동작은 유지한다.
- `역사 현장 3`에서 세 장면에 들어간다. 장면마다 4명 목소리의 대화가 두 차례 이어지고, 두 번째에 다른 참여자들이 합류한다. 선택은 개인 기록으로 남고 사실에 해당하는 결과는 고정한다. 장면 속 인물은 플레이어 인물 목록에 추가되지 않는다.
- 마무리에서 개입 기록·실제 역사·정확한 기록 locator와 원문 링크를 보여준다. 행사 날짜는 화면에서 당시 러시아 역법을 병기하고 저장용 ISO 날짜는 새 역법으로 둔다.
- 캔버스 강조는 역할·퀘스트·출입 조건을 통과한 오브젝트에만 적용한다. 현장 주민의 짧은 말풍선은 18초 주기 중 제한된 구간에만 나타나고, 플레이어와 대화 중에는 숨긴다.

## 접근 방식

1. 세 사건을 기존 플레이에 삽입: 연대기·저장·인물 시대가 맞지 않고 기존 장의 인과를 오염하므로 제외.
2. 정적 대화 장면 세 개: 저비용이나 이동·합류·직접 참여 요구를 충족하지 못하므로 제외.
3. 독립된 출처 기반 역사 현장 세 개: 전용 상단 버튼에서 각 장면을 시작하고, 두 차례의 그룹 대화·즉시 방향이 보이는 선택·개인 개입 기록·고정된 역사 결과·원문 링크를 한 화면 흐름으로 제공한다. 이를 채택했다. 별도 지도 없이 1847년 저장 상태와 연표를 보존한다.

## 기술 제약

기존 Vercel API와 결정론적 RPG 상태 엔진을 유지한다. Cloudflare를 추가하지 않는다. 기존 다섯 엔딩과 1847–49 캠페인 상태를 변경하지 않는다. 실제 역사 인물은 모든 빙의 진입점에서 거부된다. 모바일 레이아웃과 reduced-motion 설정을 유지한다.

## 사료 후보

- 1825: GARF 디지털 사료—1825년 12월 14일(당시 러시아 역법) 봉기 문서, 상원 선언 초안, 1826년 조사 증언. 역사적 결과는 봉기 진압과 이어진 체포로 고정한다.
- 1836: 고골의 1836년 4월 29일 Щепкин 서신과 극장 공연의 동시대 기록. 공연 중 대사는 새로 만들지 않고, 편지에 기록된 반응 및 장면 참여자의 창작 대화를 분리한다.
- 1861: 2월 19일 선언문 원문·RGIA 보관 정보, 3월 5일 상트페테르부르크 공표 결정/절차 기록. 선언문과 시행 규정의 차이를 다룬다.

## 성공 기준

- AI가 직접 질문에 답하고, 이유 없는 주제 전환·자기 독백·문장 파손을 줄인다. 실패하면 비어 있는 실패 원인과 같은 말 재시도 흐름을 제공한다.
- 현재 인물이 사용할 수 없는 인터랙션은 강조하지 않는다. 사용할 수 있는 자료·출구·현장 오브젝트는 한눈에 구분된다.
- 주변 짧은 대화는 낮은 빈도로 나타나며 사용자 대화를 덮지 않고, reduced-motion에서 정지 표현으로 남는다.
- 새 역사 장면 3개 모두 출처 열람, 4인 이상 상호작용/합류, 플레이어 개입, 종료 후 역사 결과·자료 검토, 실제 인물 빙의 차단을 검증한다.
