# 200% text zoom browser check

검사 시각: 2026-10-04

Codex in-app browser의 실제 실행 탭 `http://127.0.0.1:4173/#v28`에서 브라우저 확대 입력을 적용하고, C01 도착 화면과 알렉세이 선택 후 반응 화면을 직접 확인했다. 200% 확대 상태에서 문서 제목, 화자명, 대사, 선택 버튼이 읽히고 선택 후 `봉투를 펼쳐 본다` 반응 버튼이 나타났다. 선택지와 자료는 세로로 이어져 스크롤 가능한 상태이며, 수평 페이지 잘림은 보이지 않았다.

이 기록은 headed UI에서 직접 확인한 결과이며, CUA 캡처 바이트를 작업트리의 PNG로 보존하는 기능은 이 환경에서 제공되지 않아 raw 200% PNG를 별도 ZIP 증거로 포함했다고 주장하지 않는다. 따라서 `ISSUE_TRIAGE.csv`의 `V28-200P-TEXT-ZOOM`은 P2 증거 위생 항목으로 유지한다. 실제 사람 플레이테스트 상태도 별도로 `PENDING`이다.

추가로 Playwright headed 실행에서 브라우저 확대 단축키를 네 차례 적용해 확인했지만, 이 실행 환경에서는 `devicePixelRatio≈1`, `innerWidth=1440`으로 유지되어 실제 200% 확대가 적용되지 않았다. 해당 실행에서 생성한 PNG는 200% 증거로 보관하거나 사용하지 않았다.
