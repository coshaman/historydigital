# Russian Lives: Act III — Character Bible (V28)

## 알렉세이 오를로프

- 1836년 27세, 1849년 40세. 상트페테르부르크 관청의 등록·봉인·전달 기록을 다루는 하급 서기.
- 욕망: 가족에게 돌아갈 수 있는 경력을 지키면서도 기록의 빈칸을 방치하지 않는 것.
- 비밀: 형의 이름이 오래된 감시 목록의 가장자리에서 지워지지 않았다.
- 약점: 위험이 커지면 규정과 숫자 뒤로 숨는다. 신뢰가 깊어질수록 농담으로 두려움을 드러낸다.
- 말투: 짧고 건조하다. 봉인, 날짜, 칸을 먼저 말하며 감정을 직접 이름 붙이지 않는다.
- 갈등 방아쇠: 플레이어가 출처 없는 의도를 공식 기록처럼 쓰는 순간.
- 신뢰 변화: 출발·수신·열람을 분리해 말하면 봉인 기록을 보여 준다. 이름을 함부로 적으면 손을 거둔다.
- 거짓말 조건: 형의 흔적이 드러날 때만 출발 시각을 흐린다. 플레이어가 원문을 직접 확인하면 정정한다.
- 감정 샘플: 평온 `봉인은 그대로야.` / 경계 `그 날짜를 어디서 봤지?` / 빈정거림 `칸을 하나 더 만들면 세상이 덜 무서워지나?` / 두려움 `그 이름은 지금 적지 말자.` / 신뢰 `이번에는 네 문장 옆에 내 이름을 두지.`

## 예카테리나 벨로바

- 1836년 24세, 1849년 37세. 서점과 인쇄소 사이의 합법적 독서·전달망을 잇는 민간인.
- 욕망: 건넬 수 있는 글과 사람의 이름을 지키며 인쇄망의 신뢰를 잃지 않는 것.
- 비밀: 동생에게 보내지 못한 봉투가 작업장 바닥판 아래 있다.
- 약점: 허세로 아는 척하는 사람에게는 정보를 주지 않는다. 침묵을 거짓말로 오해받는 일을 두려워한다.
- 말투: 질문이 먼저다. 빠른 관찰, 지명, 날짜를 섞고 짧은 비꼼으로 경계를 세운다.
- 갈등 방아쇠: 공고·편지·소문을 한 사람의 의도로 뭉개는 말.
- 신뢰 변화: 원문을 직접 읽고 모르는 것을 모른다고 하면 다음 봉투를 보인다. 이름을 보호하면 거리의 소문을 막아 준다.
- 거짓말 조건: 동생의 봉투가 노출될 때만 작업장 위치를 바꿔 말한다. 증거를 함께 보면 즉시 고친다.
- 감정 샘플: 평온 `그 줄은 그대로 읽어요.` / 경계 `그 이름을 누가 먼저 말했죠?` / 빈정거림 `요약이 원문보다 오래 사는 날도 있군요.` / 두려움 `오늘은 그 봉투를 보이지 않는 편이 낫겠어요.` / 신뢰 `당신에게는 접힌 선까지 보여 주죠.`

## 파벨 안토노프

- 1836년 31세, 1849년 44세. 우편소와 마차·도보 전달 경로를 아는 연락원.
- 욕망: 봉투가 누구 손에서 누구 손으로 갔는지 거짓 없이 남기고 자기 노선을 지키는 것.
- 비밀: 폭설 때 배달하지 못한 봉투 하나의 발신인을 확인하지 못했다.
- 약점: 직접적인 정치어를 피한다. 독촉받으면 침묵하지 못하고 지연 시간을 말한다.
- 말투: 날씨, 거리, 도착 시각을 먼저 말한다. 사람을 판단하기보다 경로를 계산한다.
- 갈등 방아쇠: 봉투를 맡기지 않고 전달 결과를 이미 사실처럼 쓰는 행위.
- 신뢰 변화: 발신·수신·열람을 실제로 맡기면 지연과 위험을 함께 알린다. 독촉하면 위험한 이름을 지운다.
- 거짓말 조건: 봉투의 발신인이 위협받을 때 도착 시간을 늦춰 말한다. 직접 들은 사실을 보여 주면 정정한다.
- 감정 샘플: 평온 `길은 마르지 않았지만 봉투는 도착했습니다.` / 경계 `이름은 봉투보다 먼저 움직입니다.` / 빈정거림 `눈이 그친다고 소식까지 제때 오는 건 아니지요.` / 두려움 `오늘은 이 문을 다시 지나지 않는 편이 낫습니다.` / 신뢰 `당신이 맡긴 시간은 그대로 배달하겠습니다.`
