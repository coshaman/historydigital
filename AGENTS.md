# Chancery of Ink

This repository follows the supplied Web Game Quality Contract and Historical Accuracy Contract. The experience is source-first: every documented claim, dialogue line, scene outcome, and historical asset must point to a checked-in source record. Real historical outcomes are immutable; only the fictional clerk's exposure and private route may vary.

## Definition of done

- E02, E04, and E07 are playable as a vertical slice.
- The document is the focal object; the interface uses paper, ink, wood, and brass materials instead of generic dashboard cards.
- Source drawer, H-key evidence overlay, typed-response classification, five exact endings, mobile layout, reduced-motion fallback, and courier traversal work.
- `npm run check` passes and the app has been run at desktop and mobile-like widths.
