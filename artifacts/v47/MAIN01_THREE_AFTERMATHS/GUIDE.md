# 금지된 삽화 연감 · 마지막 장부 공략

**시작**　상단 **역사 현장 → 금지된 삽화 연감**. 첫 장면에서는 레프의 시점으로 서점 안 구독 장부를 살핀다. 다음 장면마다 수첩에 표시된 인물로 바꾸고, 목적지에서 **E** 또는 **살펴보기**를 누른다.

**마지막 선택**　1848년 12월 12일, 네프스키 인쇄소. 예카테리나로 구독자 편지를 열어 끝까지 읽고 **읽음**을 누른다. 편지를 읽은 뒤 인쇄소의 장부 앞으로 돌아온다. 아래 세 경로에서는 니콜라이 네크라소프로 빙의해 장부를 열었다.

| 마지막 장부에서 누른 선택 | 현장에 남는 결과 | 화면 |
| --- | --- | --- |
| 한 부를 감추고 작업자 품삯을 준다 | 편집부가 연감 한 부를 따로 보관하고 스테판의 품삯부터 정산한다. 환불은 늦어진다. | [품삯 정산](workers/NORMAL-MAIN01-aftermath.png) |
| 환불 명단을 서점에 넘긴다 | 레프가 환불 대상 명단을 받는다. 작업자들은 남은 품삯을 받지 못하고 다른 일을 찾는다. | [구독자 환불](subscribers/NORMAL-MAIN01-aftermath.png) |
| 급료를 잇도록 새 인쇄 일을 구한다 | 레프가 소개장을 써 주고 스테판이 새 일자리를 찾아 나선다. 당장 받을 품삯은 줄어든다. | [인쇄 일자리](work/NORMAL-MAIN01-aftermath.png) |

현장 기록 아래에서 **1849년으로 이어가기**를 누르면 1849년 3월 20일로 넘어간다. 저장을 다시 읽어도 마지막 장부와 그때 선택한 결과가 남는다.

## 발표 자료

연감의 인쇄와 배포 금지가 같은 작업장의 세 사람에게 어떤 차이를 만드는지 보여 주려면 마지막 화면 세 장을 나란히 놓는다. 첫 화면에는 작업자의 품삯과 남겨둔 사본, 둘째 화면에는 서점의 환불 명단, 셋째 화면에는 새 인쇄소의 소개장이 나온다. 앞에서 읽은 구독자 편지를 함께 보여 주면 환불이 왜 쟁점이 됐는지 설명할 수 있다.

## 검증 범위

세 경로 모두 각각 시작부터 12단계를 진행했다. 각 경로의 브라우저 기록은 9명에게 빙의하고 6곳을 방문했으며 페이지 오류는 0건이었다. 품삯·환불 경로는 1440×900, 일자리 경로는 390×844에서 확인했다. [경로별 선택·사료·장부 기록](SUMMARY.json)

위 세 가지는 연감 이야기의 후일담이다. 캠페인 전체의 다섯 엔딩은 별도의 마지막 기록에서 열리며, 데이터와 게임 엔진을 사용한 회귀 검증에서 각 엔딩으로 이어지는 대표 경로가 하나씩 통과했다. [다섯 엔딩 회귀 기록](../ENDING_REGRESSION/V47_FIVE_ENDING_REGRESSION.json)

## 재현

`npm run build:v33`으로 빌드한다. `PLAYWRIGHT_EXECUTABLE_PATH`를 설치된 Chrome 경로로, `V47_MAIN01_FINAL_CHOICE`를 `SUMMARY.json`의 `actionId` 중 하나로 설정한다. `V47_REPLAY_OUTPUT`을 새 출력 폴더로 설정하고 `node scripts/v47-browser-campaign-replay.mjs --main01-only --normal-only`를 실행한다. 모바일 화면은 `V47_REPLAY_VIEWPORT=390x844`로 재현한다.
