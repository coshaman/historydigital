# MAIN01 독립 베타테스트

## 처음 플레이한 경로

게임을 처음 본 독립 테스터가 새 Chrome 세션에서 배포판의 《금지된 삽화 연감》을 플레이했다. 화면에 보이는 버튼과 이동 안내만 사용했고 대화 API는 차단했다.

1. 역사 현장에서 이야기를 시작해 레프로 구독 장부를 확인했다.
2. 3월 9일 인쇄소에 들어가 예카테리나에게 빙의했다. 견본에 맞춰 표제를 조판하고 인쇄 작업 7단계를 마쳤다.
3. 4월 28일 파벨로 바꿔 서점에 들어갔고 예약금 일부를 돌려줬다.
4. 5월 18일 아브도티야로 인쇄소에 들어가 「탈니코프 가족」 첫 장을 읽고 수첩에 남겼다. 이 장면의 선택지를 연 곳에서 테스트를 마쳤다.

## 발견한 문제와 수정

| 발견한 문제 | 수정 |
| --- | --- |
| 첫 화면에서 이야기 탭을 눌러도 이야기가 시작되지 않았다. | 이야기 탭과 상단 역사 현장이 같은 시작 동작을 실행한다. |
| 예카테리나나 파벨에게 빙의하라는 안내를 따라 E를 누르면 대화나 주변 자료가 열렸다. | 현재 목표 인물이 가까이 있으면 E가 해당 인물의 빙의 버튼을 먼저 연다. 먼 곳의 인물은 목록에서도 고를 수 있다고 안내한다. |
| 모바일에서 첫 장면의 대사 다섯 발화 중 처음 두 발화만 바로 보였다. | 선택지가 열린 동안 지도를 줄여 대사와 선택지에 공간을 준다. 긴 대사는 계속 스크롤할 수 있다. |
| 모바일 목표창에서 중복 이야기 탭이 현재 행동을 밀어냈다. | 진행 중에는 상단 역사 현장 메뉴를 통해 이야기를 고른다. 목표창에는 지금 할 일이 먼저 보인다. |
| 토론 대상으로 지정한 인물 대신 더 가까운 NPC에게 말이 걸렸다. | 선택한 증인을 대화 버튼에 우선 연결한다. 인사는 진행으로 계산하지 않으며, 두 입장을 들으면 수첩에서 내 입장을 기록할 수 있다. |

## 수정 빌드 검증

- 새 브라우저에서 상단 메뉴와 첫 화면 탭으로 각각 시작했다. 3월 9일 장면에서 파벨이 더 가까운 상황을 재현해 예카테리나 빙의와 인쇄 작업 목표가 이어짐을 확인했다.
- 390×844에서 첫 장면 대사 다섯 발화와 선택지 두 개를 한 화면에서 확인했다. [첫 장면](main01-opening-dialogue-390.png) · [인쇄 작업 목표](main01-next-action-390.png)
- 390×844에서 API가 HTTP 503을 돌려주는 상태를 재현했다. 소피야와 아브도티야에게 작품에 대한 답을 들은 뒤 입장을 고르고 저장을 확인했다. [수첩의 입장 선택](main01-discussion-stance-390.png)
- 브라우저 회귀 테스트는 1365×768에서 일반 경로 12개 장면을 모두 완료했다. 아홉 명에게 빙의했고 여섯 곳을 거쳐 후일담과 1849년으로 이어가기 버튼을 확인했다. [후일담 화면](ROUTE/NORMAL-MAIN01-aftermath.png) · [경로 로그](ROUTE/V47_NORMAL_MAIN01_BROWSER_CAMPAIGN.json)

독립 테스터는 5월 18일 독서 장면까지 도달했다. 후일담까지의 결과는 개발 회귀 테스트에서 확인했다.
