# 혁명의 소식과 마지막 금요일

상단 **역사 현장 → 혁명의 소식과 마지막 금요일**에서 시작한다. 날짜가 바뀔 때마다 수첩에서 지금 할 일과 맡을 인물을 확인한다. 목표 인물 가까이에서 **E**를 누르거나 상단 **인물 목록**에서 바로 바꿀 수 있다.

| 장면 | 따라갈 수 있는 경로 |
| --- | --- |
| 혁명 소식 | 알렉세이로 인쇄소에 들어가 소식이 도착하면 선언문을 읽고 전달 범위를 선택한다. |
| 모임과 사전 | 소피야로 여관 모임을 열고 바실리로 책방의 푸리에 관련 사전 항목을 읽는다. 책을 빌릴지 대목을 베껴 둘지 고른다. |
| 농노제 토론 | 여관에서 수첩의 대화 목표를 고른다. 바실리로 안드레이에게 농노가 일과 거처를 정할 권리를 묻고, 예카테리나 등 다른 인물로 바꿔 바실리의 의견을 듣는다. **수첩 → 해야 할 일**에서 입장을 고르면 끝난다. |
| 초대장과 편지 | 파벨이나 엘리자베타로 초대장을 맡는다. 다음 장면에서 벨린스키 편지 필사본을 읽으면 책방에서 사본을 어떻게 다룰지 선택할 수 있다. |
| 감시와 체포 | 이반으로 거리에서 방문객을 살핀다. 관리와 서기로 바꿔 명령과 보고를 읽고, 체포 현장과 접수실에서 대응을 고른다. |
| 세묘노프 광장 | 광장의 현장 선택을 마친 뒤 바실리로 가족을 대기 장소로 안내하거나 목격한 일을 개인 기록으로 남긴다. |

일반 경로는 브라우저에서 12개 장면을 완료했다. 아홉 명에게 빙의해 여덟 곳을 방문했고 페이지 오류는 없었다. [완주 경로와 선택 기록](../MAIN03_DISCUSSION_ROUTE/V47_NORMAL_MAIN03_BROWSER_CAMPAIGN.json) · [광장 후일담](../MAIN03_DISCUSSION_ROUTE/NORMAL-MAIN03-aftermath.png)

## 토론을 이어서 하기

질문에 답을 받으면 수첩에 한 사람의 답이 기록되고 다음 상대가 표시된다. 중간에 새로고침해도 목표와 진행을 이어갈 수 있다. 토론을 나중에 마치고 싶으면 **메인 목표로 돌아가기**를 누른다.

390×844 브라우저에서 직접 입력한 질문과 화면에 표시된 질문으로 각각 다른 사람의 답을 기록했다. 첫 답을 들은 뒤 새로고침하고 몸을 바꿔 두 번째 답을 들었다. 마지막에 두 입장이 스크롤 없이 보였다. 모델 응답은 모의 결과를 사용했다. [응답과 출처 전달 기록](main03-discussion.json) · [수첩의 입장 선택 화면](main03-discussion-stance-390.png)
